# First release targets OpenCode V2 only

The first published package is an OpenCode V2 server plugin. It does not also export a V1 `server()` event hook.

V1 and V2 plugin APIs are intentionally different, and V1's `session.idle` / `permission.asked` names are not the V2 contract. A dual export would freeze two lifecycles onto one semver line. V1 support, if it ever exists, is a separate package or a later major, not a compatibility shim in this one.
